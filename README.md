
# Mental Health in Technology — Unsupervised ML Case Study

A data science project analysing mental health survey data from technology-oriented employees. The goal is to identify meaningful clusters of participants and provide HR with clear, actionable insights for a targeted mental health support programme.

Developed as part of the course *Machine Learning — Unsupervised Learning and Feature Engineering* at IU International University of Applied Sciences.

---

## Project Goal

The dataset is high-dimensional, contains missing values, and includes non-standardised text responses. The main objectives of this project are:

- Explore and understand the survey data
- Clean and preprocess the data
- Engineer meaningful features
- Reduce dimensionality while preserving key information
- Cluster participants into meaningful groups
- Interpret the clusters and derive actionable insights for HR

## Dataset

- **Expected file name:** `mental-health-in-tech-2016.csv`
- **Target location:** `data/raw/`
- **Size:** 1,433 respondents × 63 columns (0 duplicate rows)

The dataset is the *OSMI Mental Health in Tech Survey 2016* (Open Sourcing Mental Illness, LTD). It contains over 1,400 responses measuring attitudes towards mental health in the tech workplace and the prevalence of mental health disorders among tech workers.

## How to Run

### Prerequisites

- Python 3.10 or newer
- pip
- Jupyter Notebook or JupyterLab
- (Optional) A virtual environment tool such as `venv` or `conda`

### Step 1 — Clone the repository

```bash
git clone https://github.com/Massaquoi716/iu-mental-health-tech-clustering-caseStudy.git
cd iu-mental-health-tech-clustering-caseStudy
```

### Step 2 — Set up the dataset

Follow the **Dataset** section above to place `mental-health-in-tech-2016.csv` inside `data/raw/`. Verify the file is present:

```bash
ls -lh data/raw/mental-health-in-tech-2016.csv
```

### Step 3 — Create a virtual environment and install dependencies (Just a recommendation)

**Linux / macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

**Windows (PowerShell):**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

**Windows (cmd.exe):**

```cmd
python -m venv .venv
.venv\Scripts\activate.bat
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Step 4 — Launch Jupyter

```bash
jupyter notebook
```

or, if you prefer JupyterLab:

```bash
jupyter lab
```

### Step 5 — Run the notebooks in order

Execute the notebooks in the following sequence. Each notebook depends on the artifacts produced by the previous ones.

1. `notebooks/01_eda_and_data_understanding.ipynb`
2. `notebooks/02_data_preprocessing.ipynb`
3. `notebooks/03_feature_engineering.ipynb`
4. `notebooks/04_dimensionality_reduction.ipynb`
5. `notebooks/05_clustering_and_visualization.ipynb`

> **Note:** The `data/processed/` folder is generated automatically when running the notebooks. Run Notebook 1 first to regenerate the derived artefacts used by later notebooks.
